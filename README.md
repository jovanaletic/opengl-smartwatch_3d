# opengl-smartwatch_3d

Kratak opis:
- Ovo je projekat iz predmeta Racunarska grafika.

Short description:
- This is a Computer Graphics course project.
- The project is implemented in C++ using OpenGL (GLFW/GLEW/GLM).
